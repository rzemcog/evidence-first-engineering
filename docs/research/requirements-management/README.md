# Исследование: управление требованиями для EBT-first

**Статус:** первичный исследовательский цикл, по состоянию на 2026-11-12. **Не является** утверждённой архитектурой, готовым гайдом или результатом практического тестирования.

Цель: двунаправленно сопоставлять требования [D-001–D-013](../../decisions.md) с уже существующими решениями, а внешние находки использовать для формирования предложений по уточнению требований. Не принимать найденный механизм в качестве обязательного без пользовательского утверждения.

## Артефакты цикла

1. [Сравнительная матрица — первый проход](2026-11-12-comparison.md): GRACE 4, OpenSpec, GitHub Spec Kit, Kiro, Doorstop; первоисточники и ограничения выводов.
2. [GRACE 4 — проверка контура требований](2026-11-12-grace-requirements.md): что подтверждено публичным кодом и skills, а что известно только из пользовательских публикаций.
3. [Утверждённая методика исследования](2026-11-12-research-methodology.md): приоритет источников, кода и архитектурного анализа.
4. [Исторический план T01–T07](experiments-plan.md): не выполнен и **не является обязательным этапом** после D-014.

## Правила сохранения research

- Каждый законченный срез исследования коммитить с датой, перечнем источников, степенью уверенности и нерешёнными вопросами.
- Новые факты **добавлять отдельной ревизией**, а не незаметно переписывать историю выводов; предыдущее состояние доступно в истории Git.
- Отличать **продуктовую документацию**, **проверку исходного кода**, **практический эксперимент** и **неподтверждённое утверждение автора**.
- Новая возможность готового инструмента даёт основание предложить draft требования, но **не вносит автоматических изменений** в согласованные D-решения.
- Имеющиеся результаты — **документальный анализ**, тестовые сценарии разработаны, но ещё **не выполнены**.

## Следующее действие

Продолжить разбор открытого кода, спецификаций, интерфейсов и ограничений кандидатов; сохранить механизмы, идеи и варианты комбинирования. Точечные технические проверки запускать лишь для конкретных вопросов, не разрешённых исследованием источников. Отдельное сравнение недетерминированного поведения агентов не входит в текущие цели.
